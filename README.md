# Anas Khan — Selected Work Showcase

A minimalist, professional educational media portfolio showcase built for internship application to **IIT Madras CODE**.

## 🚀 Features

- **Minimalist Dark Aesthetic**: Built with Inter typography, Instrument Serif editorial accents, cyan (`#00f2c3`) highlights, and floating translucent pill navigation.
- **Pure Static Stack**: HTML5, CSS3, Vanilla JS. Zero frameworks, zero build step.
- **Selected Showcase Sections**:
  - **Video Work**: YouTube video previews & view stats.
  - **Scripts & Writing**: Research-based scripts & podcast interview frameworks.
  - **Blogging & Research**: 60+ published blogs & 500K+ impressions stats.
  - **Thumbnail Showcase**: Visual thumbnail grid linked to live thumbnail portfolio.
- **7 Micro-Interactions**:
  - Bespoke custom smooth cursor & ring follower.
  - Magnetic buttons & nav targets.
  - Navbar scroll progress indicator line.
  - Radial cursor spotlight glow on cards.
  - Subtle 3D card tilt on hover.
  - One-click "Email Copied! ✓" clipboard feedback.
  - Hardware-accelerated scroll reveal animations.

## 🛠️ Tech Stack

- **HTML5** (Semantic structure)
- **CSS3** (Custom properties & modern flex/grid layouts)
- **Vanilla JavaScript** (ES6+)
